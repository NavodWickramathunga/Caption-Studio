Posting to

Posting to Facebook? Facebook only accepts .SRT, and only if the filename ends in .en_US.srt — the button above does that for you. Upload the video first, then add the caption file to the same post.

Reels won't take .webm. Facebook wants MP4 (H.264 + AAC), 1080×1920, up to 90 seconds. Convert the recording with:
ffmpeg -i captioned.webm -c:v libx264 -preset slow -crf 20 -pix_fmt yuv420p -c:a aac -b:a 128k -vf "scale=1080:1920" out.mp4

Better still, skip the recording: burn the .ASS captions straight onto your original clip — sharper text and no quality lost to re-encoding.
ffmpeg -i clip.mp4 -vf "ass=captions.ass" -c:v libx264 -crf 20 -pix_fmt yuv420p -c:a aac out.mp4
Burning in with ffmpeg: ffmpeg -i clip.mp4 -vf "ass=captions.ass" -c:a copy out.mp4 — the .ass file asks for the Anton font, so Anton needs to be installed on whichever machine runs ffmpeg.
